# PEAK LAB | Официальный магазин спортивного питания в Казахстане

Лендинг-витрина спортивного питания бренда **PEAK LAB** с полным ассортиментом, ценами в **тенге (₸)**, минималистичным чистым дизайном и интеграцией условий доставки/оплаты по Казахстану (Kaspi Pay / Red 0-0-3).

---

## 🚀 Как открыть проект локально

Сервер запущен и доступен по адресу:
👉 **[http://localhost:3000](http://localhost:3000)**

## 📋 Что реализовано по требованиям

### 1. Цены в тенге (₸)
- Все ценники, скидки, пороги бесплатной доставки (от 25 000 ₸) и номиналы промокодов (3 000 ₸) переведены в национальную валюту Казахстана (₸ / KZT).
- Интеграция способов оплаты: **Kaspi QR**, рассрочка **Kaspi Red 0-0-3** на 3 месяца, наложенный платеж при получении.

### 2. Сдержанный минималистичный дизайн
- Убран кричащий и перегруженный неон.
- Реализована строгая, дорогая палитра: глубокий графит/цинк (`#090a0d`, `#101217`, `#151820`), аккуратная граница блоков (`#232733`) и точечный сдержанный акцент.
- Чистая типографика (Apple SF Pro Display / Inter), лаконичные отступы и отсутствие визуального шума.

### 3. Разнообразие категорий спортпита
В витрину включен весь спектр добавок с фильтрацией по табам:
1. **Протеины**: *ISO-PEAK Whey Isolate 90%* (19 990 ₸) и *100% GOLDEN WHEY Concentrate* (15 990 ₸).
2. **Креатин**: *CREA-PEAK Creapure® Monohydrate* микронизированный (8 990 ₸).
3. **Гейнеры**: *MASS-PEAK Clean Gainer Complex* на овсяных углеводах (21 490 ₸).
4. **Предтренировочные комплексы**: *PRE-IGNITE High-Focus Matrix* с цитруллином и бета-аланином (14 990 ₸).
5. **Аминокислоты**: *HYDRO-EAA + Electrolyte Balance* (12 490 ₸).
6. **Витамины и суставы**: *OMEGA-3 Ultra Triglyceride* (7 990 ₸) и *JOINT-SHIELD Glucosamine* (8 490 ₸).

### 4. Витрина товаров и реальные фотографии
- Фотографии упаковок, банок и добавок в каждой карточке.
- Информативные бейджи: объем (граммы, капсулы, порции), вкусовая гамма, краткое описание преимуществ.
- **Интерактивная корзина (Slide-over Cart Drawer)** с подсчетом суммы, количества позиций, автоматическим расчетом бесплатной доставки и формой заказа.
- **Лид-магнит для рынка РК**: Гайд по спортпиту в WhatsApp + персональный промокод на 3 000 ₸.
- **Калькулятор нормы белка** с адаптацией под цели (масса, рельеф, сушка).
